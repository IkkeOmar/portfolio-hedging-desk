# The thread: scam to system

**Status: FINAL, paste-ready.** Every number in it is produced by the code in
these two repositories, and `scripts/audit_thread.py` checks that
mechanically: the tweet lengths, every number against the artefact it comes
from, the style rules, the links, and whether the failing gate is reported.
It runs in CI, so a number that drifts out of the post fails the build.

**Voice:** the `ttq-branding` skill. Shape: "the content shape this repo
earns: scam to system, published with the audit."

**The thread is published from this repository** (`hedging-agent-public`),
because the gate result it leads with is this repository's, and because the
thread names both repositories. The desk is the other half:
[`portfolio-hedging-desk`](https://github.com/IkkeOmar/portfolio-hedging-desk).

warning about. It lives in the repository, where its scope is stated.

## The checks `scripts/audit_thread.py` runs

- **T1** every tweet is at most 280 characters.
- **T2** every number is produced by the code, the trap ledger or the
  literature, or is one of a small, explicitly documented set of figures
  quoted from the audited post.
- **T3** every number quoted from the audited post is attributed to it in
  the thread itself.
- **T4** no emoji, no hashtags, no em-dashes, no engagement bait.
- **T5** the thread claims neither live trading nor a predictive edge.
- **T6** the failing gate is reported, and so are our own defects.
- **T7** both repositories are linked, and the video is linked once.
- **T8** the thread states that it is a starting point, and names the
  continuation.

Run it from the repository root:

```
python scripts/audit_thread.py
```
